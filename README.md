# Python Exercises

Small exercises I wrote while learning Python fundamentals. Each folder focuses on one topic.

## Contents

- **1-fundamentals**: conditionals, loops and a list accumulator.
- **2-error-handling**: handling `KeyError` with `try/except` and searching a dictionary by value.
- **3-modularization**: a small contacts app split into functions that saves and loads data from a JSON file.

## How to run

Requires Python 3. From the root of the repo:

    python 3-modularization/modular_table_app.py
